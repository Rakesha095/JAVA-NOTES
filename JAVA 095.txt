2] Print n natural numbers:(while)

PROGRAM :
import java.util.*;
class Main {
    public static void main(String[] args) {
  Scanner sc=new Scanner(System.in);
  System.out.println("Enter the n value:");
  int a = sc.nextInt();
  int i=1;
  while(a>=i)
  {
      System.out.println(i);
      i++;
  }
    }
}

OUTPUT:
Enter the n value:
12
1
2
3
4
5
6
