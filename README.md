# Java Code Repository

This repository contains Java programs for various algorithms and problem-solving tasks. Each Java file is well-documented with explanations and example inputs/outputs.

## 📂 Project Structure

- `/src` - Contains Java source files (`.java`).
- `/bin` - Compiled Java class files (if applicable).
- `README.md` - Documentation for understanding and using the code.
- `.gitignore` - Ignores compiled `.class` files and IDE-specific files.

## 🛠 Prerequisites

Ensure you have the following installed before running the Java programs:

- **Java Development Kit (JDK)** (Version 8 or later)  
  Download: [JDK Download](https://www.oracle.com/java/technologies/javase-downloads.html)

- **Java Compiler (`javac`) and Java Runtime (`java`)**  
  Check installation by running:
  ```sh
  javac -version
  java -version
